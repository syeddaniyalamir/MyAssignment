# React Assignment

This is my React assignment. In this project, I have practiced different React concepts by creating a Counter, Posts Cards, and Students Table.

## Features

- **See Counter:** Click this button to test the counter functionality.
- **See Posts:** Click this button to fetch posts from an API and display them in cards.
- **See Table:** Click this button to view student records from a local JSON file in a table.

## Technologies Used

- React JS
- React Router DOM
- React Bootstrap
- CSS Modules
- JSON Data
- Fake API

## React Hooks Used

- **useState:** To manage and update component data.
- **useEffect:** To fetch API data and handle side effects.
- **useNavigate:** To navigate between different pages using React Router DOM.

## Instructions

1. Download or clone this project to your computer.
2. Open the project folder in VS Code.
3. Open the terminal in the project folder.
4. The `node_modules` folder is not included in the project, so run this command to install the required dependencies:

   npm i || npm install 

5. If required packages are missing, install them using:

   npm i react-router-dom react-bootstrap bootstrap

6. After installation, start the project using:

   npm run dev

7. Open the local URL shown in your terminal to view the project.

## Note

You can explore the Counter, Posts, and Students Table sections by clicking their respective buttons on the Home page.
